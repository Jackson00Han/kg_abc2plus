# 旧版中文最小演示

默认启动 `./scripts/run_playground.sh --no-open` 使用 `demo-mini-zh-v1`：
4 份中文虚构资料、6 个片段、10 个问题、2 个租户。默认打开知识构建，
刷新不自动调用检索。它用于流程演示，不替代 Stage 5A、dev-mini 回归或生产规模验证。

## 已隔离的资料

完整逐文件清单见 [隔离清单](playground-demo-isolation.v1.json)。
`datasets/dev-corpus-v1/`、`datasets/industrial-v1/`、`datasets/load-v1/`
和 `data/apple_10k_excerpt.txt` 已退出默认旧版的加载路径。
这些文件原位保留，用于教学、自动化回归和独立工业服务；不会在最小演示中
上传、嵌入或发送给模型。隔离通过显式语料配置和独立数据库实现，不移动已锁定的测试文件。

## 一轮演示

1. 选择一号泵站知识管理员，在 01 发布水泵本体。
2. 在 02 仅入库权威来源，生成专家实例草稿、导入并发布。
3. 切换维护上传身份，上传普通检修报告并抽取。
4. 切换复核或管理员身份，核对原文与实体身份，批准、拒绝或暂缓候选。
5. 管理员发布，通过检索、图谱与引用核对；继续测试质量报告、历史、回滚和文档退役。
6. 需要验证同名不合并时，再上传可选反例。
7. 点击顶部“一键重置演示”并确认，完成后自动返回 01，可重复使用相同文件和本体版本。

## 重置与服务隔离

旧版独立启动，不能在工业共用实例上整库重置。默认数据库端口已改为 17693，
避开原工业实例的 17692；可明确指定：

```sh
PLAYGROUND_BOLT_PORT=17693 ./scripts/run_playground.sh --no-open --port 8000
```

访问 `http://127.0.0.1:8000/playground`。新版保留在 `http://127.0.0.1:8002/industrial`。
两个数据库独立，旧版重置不影响新版。初始化拒绝覆盖非空数据库。
原来的 `8002/playground` 共用入口仍存在，测试本次改动请使用 `8000/playground`。

重置清空独立旧版数据库中的上传、文档版本、任务、失败记录、本体、派生数据、
复核、发布和历史；从校验后的内存向量缓存恢复 4 份种子资料，不调用 embedding 或 LLM。
保留互斥、校验和、重置状态恢复、跨页面 generation 防护和浏览器操作键清理。
重置进行中阻止业务请求；失败时保持暂停，可明确重试。
只有本地临时库提供这个维护接口，工业服务继续禁用整库重置。

首次启动仍向配置的 embedding 服务发送 6 个片段，并为两个租户预热检索。
刷新和重置不发起这些模型调用。手动检索和模型抽取按需执行，原有资源上限、
权限、身份和证据约束不变。启动脚本退出后删除自己的临时容器；再次启动是干净的一轮。

完整英文回归集仅在显式指定 `--corpus-profile dev-corpus-v1` 或工业模式下使用。
