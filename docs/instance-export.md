# 已发布实例导出

入口：`http://127.0.0.1:8002/industrial` → 选择知识库 → 质量与维护 → 知识清单
→ **导出实例 JSON**。

导出当前活动发布版本的 A-Box 快照。来源编号为空时导出整个版本；填写来源编号时
导出该来源的全部匹配记录。页面显示上限和移除勾选项不控制导出范围。
请求期间按钮显示忙碌状态，成功后显示版本和记录数；空筛选结果不生成文件。

文件格式为 `graphrag-abox-export-v1`，包含：

- 当前租户、发布 ID / generation、manifest 哈希、本体版本和导出时间。
- 实体来源提及、属性断言、关系断言及关系属性，保留稳定 ID、修订 ID、
  来源等级、形成方式、审核状态、置信度、类型、规范值、单位及适用时间。
- 文档 ID、不可变文档版本 ID、Chunk ID、序号和字符范围；结构化上下文属性
  另保留值位置、来源校验和与映射校验和。

这是结构化实例与证据引用快照；原始文档、本体定义和完整审核历史仍由各自入口管理。
此格式尚未接入直接重新导入流程，不应作为完整数据库备份或直接提交到专家导入接口。
按来源导出的文件有 `scope: document`，其中引用的实体摘要不代表包含该实体的所有来源。

## API 与边界

认证后读取：

```text
GET /v1/knowledge/publication-inventory/export
GET /v1/knowledge/publication-inventory/export?document_id=<document-id>&publication_id=<expected-active-id>
```

接口使用现有 `KNOWLEDGE_INVENTORY` 操作和 `knowledge:quality` 权限、限流与超时。
响应声明 JSON 附件和 `Cache-Control: no-store`。`publication_id` 为可选的版本预期；
页面已有清单时自动带上，版本变化则拒绝导出。切换身份、知识库、刷新清单或修改来源
筛选后的过期响应不能触发下载。

服务仍先审核当前完整发布版本，再在只读事务中重新核对 manifest、全部成员、
租户、ACL、本体、证据路径与导航投影。全量导出仅解除清单的 500 条显示限制，
保持既有 manifest、质量检查、关系属性和事务预算。达到任一边界、质量失败或成员
不完整时拒绝返回文件；不会把部分结果标成完整导出。无权限返回 403，版本、完整性
或规模冲突返回 409，依赖异常按现有 API 返回 503/504。未发布候选不在导出范围内。

## 读取兼容修复

实现导出时发现两处现有清单读取误判，均未修改已存储知识：

1. Cypher map projection 将未存储的 `literal_source_encoding` 投影成 `null`。
   `TEXT` 编码在持久化时按约定省略，质量检查现在先还原这一缺省语义，再调用严格
   类型解码；未知编码与缺失必填字段继续拒绝。关系属性使用同一解码逻辑。
2. 现有摄取将 `TBoxVersion.compile_governance_policy().policy_id` 用作关系属性的
   schema version（`tenant:key:vversion`），其父断言使用 T-Box UUID。质量检查和
   清单现在接受这两种同版本标识；策略标识必须来自当前发布所绑定且校验和匹配的
   T-Box，不能由请求指定。仍逐字段验证不可变属性、证据和物化结果。

临时开发检查、下载与截图位于 `.local/browser-qa/instance-export/`，不属于运行依赖。
