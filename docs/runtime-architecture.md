# 当前代码结构与运行依赖

## 运行链路

`quick_start.command` → `scripts/restart_workbench.py` → `scripts/run_playground.py`
→ FastAPI 工作台，监听 `127.0.0.1:8002`。

重启器读取本地配置，检查原数据库与端口进程，等待本项目旧服务正常退出后启动
新服务。服务只连接现有知识库，保持 `PLAYGROUND_PUMP_ONLY=1`，跳过外部模型预热。
上传和检索仍使用配置的真实模型；启动不会加载测试夹具、导入来源或重置数据库。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `domain` | 稳定 ID、权限主体、文档、Chunk、实体及事实模型 |
| `ontology` | 本体定义、来源文件校验、版本与启用状态 |
| `construction` | 文档解析、结构映射、抽取、上传预算及构建流程 |
| `ingestion` | 文档版本与嵌入写入、增量生命周期及向量索引 |
| `knowledge` | 来源管理、身份确认、候选复核、发布与证据关联 |
| `graph` | 数据库模式与迁移、图谱浏览、质量维护及历史发布视图 |
| `retrieval` | 受权限限制的召回、图扩展、重排与证据子图 |
| `generation` | 有引用的回答组织；当前工作台未开放最终回答权限 |
| `api` | HTTP 契约、认证、预算及业务适配 |
| `playground` | 本地工作区身份、服务页面、静态资源和水泵示例 |
| `industrial` | 现有工业 API 的范围、来源与上传适配；不包含旧语料加载器 |
| `observability` | 运行日志、指标及敏感信息脱敏 |

通用模块保留可扩展能力，不将母线槽或水泵的实例、阈值和数量写入通用本体。
`industrial/families.py` 保留既有 API 家族标识的兼容映射，它不是加载或恢复历史语料的入口。

## 文档级上下文映射

结构化 JSON 先生成记录字段映射，再通过文档级上下文补全共享属性。
`value_path` 指向值，`scope_path` 必须逐字匹配该上下文声明的范围；空字符串表示文档根。
规划器 `json-context-planner:v2` 明确这一区别，并在校验失败时返回期望与实际范围。
有待补必填字段时，空规则不能被当作有效补全结果；编译器也检查未覆盖的必填属性，
保留缺口并标为部分完成。历史空结果只调整读取时的状态解释，不覆盖其审计内容。

## 发布候选分页

`GET /v1/knowledge/publication-candidates` 支持 `limit`（1–100）和 `offset`
（0–1,000,000），返回当前页 `items`、`total`、`total_entities`、`offset`、`limit`。
来源提及与事实合并排序后分页；总数和列表复用相同的候选资格、证据与租户/ACL 条件，
读取事务限时 30 秒。列表按当前数据读取；候选发生变化后可刷新重新浏览。

发布页每页 100 条记录，明确区分全部实体与本页实体；同一实体的记录可能跨页。
选择按稳定 revision ID 跨页保留，包括已有记录的替换信息；支持本页全选和清空跨页选择。
翻页及列表刷新不因记录未出现在当前页而取消选择，切换知识库清空选择。
预览和发布继续执行原有的有效版本、权限及完整性校验；失效选择不能直接发布。

## 失败构建重试恢复（2026-09-14）

上传页面会在会话存储中保留操作编号，用于网络中断后的幂等重放。旧请求返回通用
错误时可能没有清除此编号；更换抽取模型后，同一编号对应的服务端请求指纹变化，
会被拒绝为 409。提交前现在重新读取当前身份可见的最近 25 个构建任务：只有匹配
操作编号且状态为 `FAILED` 时创建新编号。`RUNNING`、`RETRY_WAIT`、已完成或未查到
的操作仍保留编号；查询失败时不继续提交，身份变化时丢弃旧查询结果。旧失败任务、
不可变文档版本和已完成片段不删除，也不重置旧摄取任务的尝试预算。
模型调用失败与超时在任务详情中分别说明，避免仅展示笼统的中断提示。

临时检查位于 `.local/browser-qa/construction-retry/`：
`node .local/browser-qa/construction-retry/offline.cjs` 覆盖终止失败、运行、等待重试、
已完成、未查到、查询失败、身份切换七类状态，以及文件指纹变化；JavaScript 语法
与 `git diff --check` 通过。独立 Chromium 在真实 8002 / Neo4j 环境复现旧操作 409，
从会话存储恢复旧编号后，页面成功发出新编号并进入 16 个片段的实际构建。
1280、1440、1920 桌面宽度的上传状态、任务列表、明细和滚动已检查并查看截图。
