# 泵站维护知识构建操作指南

默认入口是 <http://127.0.0.1:8000/playground>，也可以使用启动时指定的端口。
进入“知识构建”，选择可构建、确认和发布的账号，并核对上传文件的访问组。
示例文件用于练习，页面执行的是实际的本体、文档、实例和发布流程。

| 流程 | 页面顺序 | 知识等级 |
| --- | --- | --- |
| 建立专家基准 | 01 保存并启用本体 → 02 上传权威文档并抽取 → 03 编辑和确认实例 → 04 发布权威图谱 | 权威文档抽取结果为权威 |
| 扩充业务知识 | 05 上传业务文档 → 06 编辑和确认实例 → 07 发布业务知识 | 业务抽取结果始终为次权威 |
| 人工补充 | 在实例区填写实体、属性或关系 → 确认 → 发布 | 次权威，来源为人工补充记录 |

等级由来源决定，人工确认、编辑和发布都不会升级等级。尚未确认的权威文档
抽取结果也有权威来源标记，但只有明确发布后才进入活动图谱。

## 本体与权威文档

在 01 输入实际本体 JSON，点击“保存并启用本体”。保存和启用在同一事务中
完成；并发版本冲突时不会残留一个只保存了一半的版本。页面不要求先导入草稿。
旧版本可以载入校验、复制为下一版本，或导出完整 JSON。导出文件的
`definition` 是本体定义，外层是版本及完整性元数据；`expected_checksum`
用于精确重放校验。修改定义时应复制到下一版本，不能修改已启用版本。

在 02 上传权威文档，系统进行切块、向量化和本体约束下的实体、属性、关系抽取。
校验失败会显示原因；原文已入库不代表已生成图谱知识。页面不会将配套实例
模板自动当作本次抽取结果，也不会自动发布。

可在示例包下载这些文件，也可使用自己的资料：

- [authoritative_source.txt](../src/graphrag_prod/playground/static/industrial-demo-v1/authoritative_source.txt)：用于 02 的权威文档。
- [maintenance_report.txt](../src/graphrag_prod/playground/static/industrial-demo-v1/maintenance_report.txt)：用于 05 的普通检修文档。
- [homonym_report.txt](../src/graphrag_prod/playground/static/industrial-demo-v1/homonym_report.txt)：同名、不同设备编码的反例。

本体中的 `EquipmentCode` 区分设备，`RatedPower` 使用 kW；名称相同不能据此合并。
模型结果可能变化，不用固定的候选数量判断成功，也不应为了凑齐示例数量反复上传。

## 编辑、确认和人工补充

实例区按实体组织来源提及、属性和关系，分别显示权威等级、来源及处理状态。
该队列显示当前账号可处理的记录；两条流程共用治理功能，切换页面不会改变等级。

先核对每条提及对应的实体，再核对属性与关系。已有实体匹配必须检查设备编码
等身份属性。同名不会自动合并；确认实体不会自动批准它的属性与关系。
逐项选择采用、不采纳或暂缓；修改后先保存并暂缓，重新检查后再采用。

文档支持的修正保留原文引用和来源等级。**超出原文的事实应在“人工补充”表单
中新建**，不能把它伪装成文档内容。表单可输入实体、属性值及单位，或实体关系。
系统不调用抽取模型，保存实际填写内容、版本、精确位置与访问组作为人工记录；
它仍需要向量化，并遵守同样的本体和数据类型校验。

引用会区分“文档原文”和“人工补充记录”。人工记录只有在当前有效发布版本中
完整发布后才能被文本检索返回；仅批准、部分发布或已撤回都不满足条件。
本次不新增人员目录、责任人维护或权限管理页面。

## 发布、检索与维护

在 04 或 07 检查已批准的记录，再明确发布。发布前再次验证来源、本体、
实体依赖、版本和访问权限。业务文档抽取结果经过人工修改后仍然是次权威。

在检索台查看原文、引用及子图；“仅权威实例”筛选的是图谱投影，普通业务
文档仍可能由文本检索召回。既有向量、BM25、RRF 和有界扩展方法保持不变。
在“查看与维护”检查清单、质量、历史及文档撤回。撤回前按页面提示先移除
活动发布中的相关记录；历史来源和审核记录保留。

原有姓名/编码纠错约束仍适用：对临时身份的提及普通暂缓或修改会产生新版本，
其旧版本依赖事实不会自动迁移。需要关联已有实体时使用“确认使用已有实体”，
该操作会原子重绑依赖事实；不要修改编码绕过身份检查。

## 失败与重试

- 本体版本冲突：刷新版本列表，确认当前启用版本，再复制为下一版本。
- 无权限：核对当前账号及所选访问组，不能通过扩大访问组绕过检查。
- 抽取拒绝或没有实例：查看分块校验结果，修正来源或本体，不自动转成人工事实。
- 正在运行：刷新任务状态，等待完成；刷新只查询，不重复执行。
- 已失败：修复依赖后重新提交；旧失败记录保留。
- 请求结果未知或等待重试：保持输入不变重试，保留原操作编号避免重复写入。

默认 `dev-mini` 文档抽取有分块、调用次数与时间上限，以页面显示和服务端配置
为准。独立工业工作台的冻结语料、上传范围及预算仍按其专门的合同管理。

如需清空本地练习数据，可使用“一键重置演示”，先核对弹窗列出的范围。
重置只属于明确的本地维护操作，与正常知识构建无关；不要重置保留业务数据的库。
启动、隔离及恢复说明见 [本地运行指南](local_playground.md)。
