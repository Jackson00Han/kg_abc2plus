# 架构与开发说明

本项目是独立的工业知识与知识图谱能力层，负责资料、本体、构建、治理、图谱和证据检索。
母线槽是当前业务样例，水泵是简单测试样例；设备类型、实例数量和业务阈值由资料与配置定义，
不写死到通用代码。实际环境入口见 [快速启动](../quick_start.md)，当前资料见 [输入说明](busway-inputs.md)。

## 项目边界

长期平台使用 DeerFlow 编排任务，本仓库提供有版本、可授权、可引用的知识接口。
平台对话、Agent 会话记忆、实时数据采集、规则执行和根因判定由外部系统负责。
知识库可管理规则正文及引用，不能将其等同于已部署算法；外部分析结果经来源登记、复核和发布
后才能沉淀为案例。当前没有因此接通完整 DeerFlow 平台、实时诊断、社区摘要或全局检索。

对接复用版本化 API，校验可信身份、租户、权限、稳定对象 ID、知识发布与本体版本、时间范围、
证据和预算。身份由服务端认证确定；Agent 不获得任意 Cypher 或数据库连接权限。

## 运行与代码入口

在 VPS 的 `/home/dev/projects/kg_abc2plus-remote` 执行：

```sh
.venv/bin/python scripts/restart_workbench.py
```

重启器调用 `scripts/run_playground.py`，FastAPI 监听 `127.0.0.1:8002`，连接现有 Neo4j。
保持 `PLAYGROUND_PUMP_ONLY=1`，启动不自动导入资料或重置数据库。启动成功不证明模型可用；
上传向量化、普通模型抽取与检索需要各自的模型配置。电脑通过 SSH 转发访问页面。

| 代码目录（均位于 `src/graphrag_prod/`） | 职责 |
| --- | --- |
| `api/`、`domain/` | HTTP 契约、认证、稳定 ID、权限及核心数据模型 |
| `ontology/` | 本体解析、约束、不可变来源版本及启用状态 |
| `construction/` | 文档解析、切片、声明式映射、模型抽取及预算 |
| `ingestion/` | 来源版本、向量化、索引和增量生命周期 |
| `knowledge/` | 身份关联、候选复核、发布、撤回及证据管理 |
| `graph/` | Neo4j 迁移、图查询、质量检查与布局制品 |

## 构建与治理

流程为：原始来源 → 不可变版本与精确 Chunk → 本体约束下的候选 → 身份确认和复核 →
发布快照 → 受权限与预算约束的图谱和检索。文件已存在、预检通过、候选已形成、已批准、
已发布是不同状态，不能互相替代。

- 本体 YAML / JSON 先诊断，再保存草稿，最后显式启用。原文哈希、规范本体校验和及版本分别保留。
- XML / Markdown 映射须在页面显式选择，不按文件名猜测。执行器确定性提取候选，预检不写库，
  `SOURCE_ONLY` 只登记来源。普通资料走本体约束模型抽取，不能静默放宽身份命名空间约束。
- 映射提取和独立重放不调用提取模型；来源向量化与后续检索仍有模型依赖。
- 映射、原文、本体和请求策略参与任务身份。修改映射、策略或模型不能覆盖旧操作和不可变证据。
  同一文档内容版本不能因切片配置变化而覆盖或混入第二套 Chunk。
- XML 关系保留真实端点及引用的精确原文；嵌套不自动证明电气连接。Markdown 保留完整表格行，
  缺失外部端点不补造，不按显示名称合并不同来源的实体。
- 当前 XML 映射使用完整证据 Chunk（最多 65,536 字符），Markdown 映射使用结构优先切片
  （3,000 字符）。模型上下文、嵌入和来源读取有独立预算；不能据此推断任意大小文件均可完整处理。
- 来源等级、形成方式、审核状态和模拟性质分别保存。组态不是实测，候选原因不是已确认根因。
- 确定性复核只提供重放证明；审批仍走既有权限、事务、追加修订和并发版本检查。复核不自动发布。
- 发布预览与正式发布绑定当前版本和预览哈希，遵守依赖闭包与每次变更预算。
  同一实体从 APPROVED 到 PUBLISHED 的直接前驱兼容仅限内容、证据、权限和审核信息完全一致。

当前母线槽的角色转换证明、测点绑定和外部观测量缺项列在 [输入说明](busway-inputs.md)，
不得通过恢复旧实例、放宽校验或引入隔离资料来补齐计数。

## 图谱、检索与导出

来源、Chunk、实体、事实使用稳定应用 ID，不使用 Neo4j 内部 ID 作为持久业务标识。
召回、图扩展、计数、来源和证据读取均执行租户、ACL 和当前发布边界。
索引只能在向量空间一致且覆盖满足要求时激活，不静默混用模型，也不绕过索引就绪检查。

完整来源证据和模型检索上下文分别管理。超长 Chunk 按预算返回连续摘录，保留完整及摘录
校验和、原文范围和不完整状态；不改写原 Chunk 或召回排序。引用失效、撤权或跨租户均拒绝。

图谱布局由 `graph/visualization.py` 与 `graph/layout.cjs` 生成，Node.js 18+ 为运行依赖。
浏览器使用随代码保留的图谱库与许可证，读取布局时仍复核授权。总览上限为 200 节点 / 300 关系，
超限不冒充完整图谱；实体档案按页读取。图谱坐标不是业务事实。

已发布 A-Box JSON 导出受权限和发布版本约束，可按来源筛选；它不是完整数据库备份，
也没有直接重新导入通路。不得将文件导出成功视为恢复流程已验证。
