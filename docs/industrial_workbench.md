# 工业知识工作台

工作台与原服务共用端口：`http://127.0.0.1:8002/industrial`。原页面仍位于
`/playground`。新页面通过认证后的领域 API 读取资料，前端图谱组件可复用于后续正式 UI。

## 从图谱开始

1. 以“工业知识管理员”查看完整的工业演示范围；切换公开、工程或维护身份，
   检查同一产品族在不同岗位下的可见内容。
2. 选择 Canalis KT 母线槽或 EvoPacT HVX 真空断路器，再选择一个当前可见的设备。
3. 按组成、分类、诊断或电气连接关系浏览。点击实体可展开邻近关系；点击连线可查看
   独立事实版本、原文依据和复核记录。
4. “本体模型”显示允许的类型与关系规则，与实例图分开。分类和物理组成是明确的
   关系语义；画布层级由布局计算，不以 `layer` 数值代表权威程度。

节点颜色区分类型；关系的实线和虚线区分权威导入与次权威类别。每条断言仍保留
自己的来源和版本。图中的“可能关联”不是已确认故障原因；设备、产品型号和
设备类别也不是同一个实体。

“权威导入”是项目内的治理类别。当前参考材料由项目整理，尚未取得企业专家认证。
合成设备记录、模型抽取、规则衍生、人工复核状态与记录置信度分别显示，不能互相
替代。记录置信度不代表诊断概率。

## 检索与阅读来源

“证据检索”支持自然语言问题、产品族和可选设备编码。工业请求使用已验证的
范围过滤和 `listwise-evidence-v1` 排序，返回精确的来源片段与引用位置。
当前服务未启用最终回答生成；页面不会把检索片段包装成诊断结论。

“来源资料”列出当前身份可读的版本和片段数。来源正文可以在入库后读取，
不要求已经产生或发布图谱事实。阅读器支持查看相邻可见片段；引用页码指
原始 PDF 的物理页码。只有原文提供的内容才能作为事实依据。

本轮 72 题检索评估与完整上下文的限制见
[检索验证](validation/industrial-retrieval.md)。三道官方 PDF 跨页、跨表题中，
两道仍未在前五条结果中收齐必要片段。手工翻阅原文是来源核对功能，不会被计作
自动检索指标的提高。

## 补充、复核与发布

1. 选择有构建职责的身份，例如“工业维护人员”，在“补充资料”中上传文件。
   可下载页面提供的合成补充资料作为操作示例。
2. 指定产品族及可见岗位。已登记设备编码可选；没有既有设备关联的新资料可留空。
   服务端固定其来源类别为 `USER_UPLOAD`，不能通过表单冒充官方资料或专家批准。
3. 选择“入库并抽取候选事实”或“仅入库”。前者受工业本体约束，后者只建立可检索
   来源，不调用事实抽取模型。
4. 切换独立复核者，例如“工业知识管理员”。先核对实体身份和来源，再复核关系。
   有已有实体建议时，核对其依据后决定是否链接；不要仅凭同名合并。
5. 填写每项复核依据，批准、拒绝或暂存候选。系统继续执行已有的复核权限、
   端点依赖和证据检查。
6. 在“发布知识”中选择已批准项，发布到新的知识版本。正常增量发布保留既有记录；
   需要替换同一记录时明确提交替换项。次权威事实不会因发布而升级为权威事实。
   发布成功后，图谱切换到所选记录的邻域；回到“图谱探索”即可检查新关系。

上述演示采用不同身份上传和复核。系统记录复核人、时间和依据，但当前没有强制
禁止具备两种职责的同一人复核自己的上传内容；岗位拆分与服务端强制职责分离
仍须区分。

设备范围选择器当前使用已有资料中明确登记的设备。上传的新实体可以审核后进入
图谱，但不会仅凭模型识别的名称自动加入设备范围选择器；新资料可先使用产品族
范围。这避免把文本中的设备提及误当成已登记的适用设备。

在线上传支持 TXT、Markdown、CSV 和 JSON，文件不超过 5 MiB。当前开发资源
边界为 LLM 模式最多 2 个片段、最多 4 次模型调用；仅入库最多 4 个片段。
PDF 通过已验证的离线规范化流程处理，当前在线表单不接收 PDF。
相同文件与元数据在同一身份下再次提交复用操作身份；网络异常后先查看任务记录。

新资料使用独立的 `industrial-upload://` 来源空间。与工业库共存时，旧页面的
全库重置入口禁用，避免删除已有工业资料。

## 组件与服务边界

- `playground/static/industrial/graph.mjs`：独立的 Cytoscape 渲染器。只接收图谱数据和
  选择回调，不持有认证、数据库或检索逻辑。
- `graph-model.mjs`：实例图和本体图转换、节点/边身份与预算检查。
- `core.mjs`：内存会话、异步身份隔离和精确引用处理。角色切换后迟到的旧结果不能
  覆盖新身份的页面；原文作为文本显示，引用按 Unicode 码点定位。
- `graph/browsing.py` 与 `api/graph.py`：已发布图谱的授权部分视图，独立于需要完整
  发布清单权限的管理接口。分页、展开和证据读取绑定知识发布、本体、语料版本与
  当前授权视图。
- `industrial/source_catalog.py`：当前授权资料目录和片段读取，包括仅入库的资料。

图谱响应最多 150 个节点、200 条边，展开最多两跳。页面加载下一页或邻域时替换
当前图形，不无限累积节点。发生版本或可见范围变化时，服务拒绝继续使用旧视图，
页面要求刷新。所有图形依赖从本地服务加载，固定版本和许可证见
`playground/static/industrial/vendor/`。

运行配置与数据保留方式见 [工业运行时与上传](industrial_runtime_and_uploads.md)。
验证记录区分离线检查、真实数据库与实际浏览器，不把本地开发样例作为现场诊断
准确率或生产环境资格证明。
