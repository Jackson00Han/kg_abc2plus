## 通用图谱展示与本体筛选

固定展示入口仅有“实例图谱”和“本体模型”。关系范围下拉框默认“全部关系”，
其他选项由当前图谱响应中的本体生成：`relationship_types` 提供关系类型，
`hierarchies` 提供显式声明并绑定有效关系的本体层级。没有层级声明就不添加层级组，
没有预设的诊断、电气连接、组成或分类标签。未知关系类型直接使用本体名称，不丢弃。
网络与层级布局是独立的可视化操作，不被当作领域关系分类。

当前水泵本体提供“安装于、包含部件、存在风险”，没有声明本体层级。筛选通过
既有图谱 API 的 `predicates` 执行，保持权限与分页边界。切换本体或知识库后清除
无效选择；本体模型不受实例关系筛选限制。空筛选结果提示具体关系范围，并提供
“查看全部关系”入口，不声称整个知识库尚未发布。
