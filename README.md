# 知识库

这是一个用于存储、管理、检索垂直领域知识的库。

## 项目定位

**专业知识管理**：本项目是一个以工业垂直领域为重点的独立知识管理与服务产品，面向智能体开发者、领域专家及有专业知识管理需求的用户。

**可信知识上下文**：项目通过整合领域本体、业务资料和知识关系，支持专业知识的接入、构建、审核、版本管理、检索与可视化，形成具有明确来源、可追溯、可持续维护的领域知识库。

**独立服务**：产品既可独立用于专业知识管理，也可通过标准化接口为不同智能体提供与任务相关、带有来源证据的知识上下文，帮助大模型减少无依据的推断，提高回答和分析的可靠性。

## 核心场景

### 1. 专业资料接入与文档知识库构建

用户上传工业领域的专业文档和结构化资料，系统完成解析、切分、向量化与索引构建，形成可检索的文档知识库。

保留原始资料、来源信息和内容位置，为检索结果提供可核查的原文依据。

### 2. 本体约束下的工业知识图谱构建

用户提供领域本体，定义实体类型、属性、关系及相关约束，指导专业知识的提取与校验。

系统利用大模型或明确配置的映射规则提取候选知识，辅助完成实体消歧、重复识别与关系关联。用户审核确认后，将知识发布到知识图谱中，避免未经确认的抽取结果直接成为正式知识。

### 3. 知识检索与智能体上下文服务（GraphRAG）

结合向量检索与图谱查询，为用户和智能体提供与问题相关的原文片段、实体信息及关系证据。

检索结果携带来源、版本与引用位置，支持智能体进一步开展问答和分析；对于证据不足、存在冲突或结果不完整的情况，明确返回相应状态。

### 4. 知识图谱浏览与证据核查

用户通过可视化界面浏览实体、属性和关系，探索知识之间的联系，并定位到支撑相关知识的原始资料。

通过图谱与原文的关联展示，辅助理解领域知识、核查抽取结果和发现需要补充或修正的内容。

### 5. 知识版本管理与历史追溯

记录来源资料、本体及知识发布的版本，保留变更内容、依据和审核记录，支持查看历史状态与版本差异。

需要恢复时，可切换到符合权限与依赖条件的历史发布版本，同时保留后续版本和操作记录，确保知识演进过程可追溯。

## 项目范围

- 知识库负责知识管理与有来源证据的上下文服务；智能体负责对话、任务编排和工具调用。
- 实时数据采集、设备控制及基于运行数据的诊断计算由外部系统负责。
- 知识库提供规则依据和候选原因，检索结果不等同于已验证的诊断结论。

## 资料与知识流程

资料登记 → 解析切分与索引 → 本体约束的知识构建（按需） → 审核发布 → 检索与展示。

资料或本体变更时保留原文和历史版本，对受影响的知识重新校验、必要时重建，并经审核后发布。
