# 母线槽诊断规则 v2（下游独立使用版）

## 0. 使用边界

| 项目 | 说明 |
|---|---|
| 文档标识 | `document_version=2.0.0`；`profile_id=diagnostic64_v2` |
| 版本状态 | 当前唯一诊断规则文件；旧版规则文件不再作为依赖 |
| 使用者 | 负责实体解析、数据查询、规则判断和结果编排的下游同事或智能体 |
| v2 进水口径 | 有效进水报警信号为 `1` 时，D4 确认 `WATER_ALARM` 现象，C1 随即确认 `WATER_INGRESS` 根因；现场检查属于处置与复核，不是输出该诊断根因的前置条件 |
| v2 三相不平衡口径 | D6 只确认 `THREE_PHASE_IMBALANCE` 现象；M3 单独表达当前无根因规则；G5 只根据 D6 结果执行负载规则门禁 |

规则来源为业务知识记录 `母线槽知识点记录 - 2026.7.10 - v1.3.md`、当前项目拓扑、当前 staging 参数以及 PO v2.1 场景。本文没有把缺失的工程参数、现场结论或生产阈值补猜出来。

## 1. 判断结果与闭环规则

### 1.1 单条规则结果

| 结果 ID | 中文含义 | 使用条件 |
|---|---|---|
| `MATCHED` | 规则命中 | 必需数据和前置条件完整，且判断条件全部满足 |
| `NOT_MATCHED` | 规则未命中 | 必需数据和前置条件完整，但判断条件不满足 |
| `INSUFFICIENT_DATA` | 数据不足 | 必需测点、质量、历史窗口、参数、绑定或拓扑证据不足；不得解释为正常 |
| `NOT_APPLICABLE` | 规则不适用 | 对象类型、拓扑位置、执行阶段或业务范围不满足规则适用条件 |

### 1.2 输出概念与断言级别

| 断言级别 ID | 中文名称 | 可以输出的内容 | 禁止行为 |
|---|---|---|---|
| `EVIDENCE_ONLY` | 仅作为证据 | 已确认的故障现象 | 不得把现象直接改写成根因 |
| `ROOT_CAUSE` | 根因结论 | 已通过 C 类完整规则确认的根因 | 不得仅凭现象名称或候选关系输出根因 |
| `NONE` | 不产生断言 | 未命中、数据不足、不适用或能力缺失 | 不得用“正常”替代数据不足 |

### 1.3 一次诊断的闭环终点

| 终点 | 必须保留的结果 |
|---|---|
| 现象未确认 | D 类规则为 `NOT_MATCHED`；不进入由该现象触发的根因判断 |
| 现象已确认且根因已确认 | 保留 D 类现象证据和所有 `MATCHED` 的 C 类根因结论 |
| 现象已确认但根因未确认 | 保留现象；列出 C 类 `NOT_MATCHED`、`INSUFFICIENT_DATA` 或缺失能力，不猜根因 |
| 数据不足 | 列出缺少的对象、测点、时间窗口、质量、参数或拓扑证据 |
| 规则不适用 | 写明不适用的对象、阶段或拓扑原因 |

同一现象允许存在多个候选根因。各根因规则独立执行；没有已定义的冲突裁决规则时，不由大模型自行排序、合并或只选择其中一个。

## 2. 总体执行顺序

| 步骤 | 下游动作 | 失败关闭要求 |
|---|---|---|
| 1 | 从问题中确定诊断对象、诊断范围和绝对时间范围 | 对象或时间范围不明确时先补齐，不扩张到无确定关联的实体 |
| 2 | 调用 `/analyze` 取得范围内部件、Port 邻接、逻辑测点和物理定位 | 未匹配部件、未配置绑定或空物理 ID 不得按名称猜测 |
| 3 | 按物理定位读取规则所需的实际数据 | 数据缺失、质量无效或时间不连续时返回 `INSUFFICIENT_DATA` |
| 4 | 执行适用的 G1～G4 数据与拓扑门禁 | 门禁只阻断其明确依赖的规则，不扩大阻断范围 |
| 5 | 执行 D6 判断三相不平衡现象，再根据 D6 结果执行 G5 | D6 只输出现象；G5 只决定 D5、C2 是否适用；D6 不启动 Phase 2 |
| 6 | 并行执行 Phase 1 的 D1～D3 | D1、D2、D3 至少一项 `MATCHED` 才启动 Phase 2 |
| 7 | Phase 2 启动后，并行执行适用的 D4、D5 和 C1～C5 | D4、D5 只输出故障现象；C1～C5 才能输出根因 |
| 8 | 汇总所有规则结果、证据和阻断原因 | 候选根因未命中或无法执行时，不补猜结论 |

场景章节用于让下游快速找到规则，不改变上述执行阶段。D4、D5、D6 不能反向启动 Phase 2；D6 命中后 G5 命中，D5、C2 为 `NOT_APPLICABLE`，C3～C5 仍按各自前置条件独立判断。

## 3. 公共数据与计算口径

### 3.1 数据口径

| 名称 | 固定口径 | 缺失或无效时 |
|---|---|---|
| 接头温升 `TempDiff` | 直接使用逻辑测点 `Item=TempDiff` 的 EDock 源值 | 不得用 `Temp-AmbientTemp` 重算、回填或覆盖 |
| 有效 `TempDiff` | `quality=GOOD`、值非空且为有限数值 | 当前样本按缺失处理，并中断所有连续持续时间 |
| 温升变化率 `TempDiffRate` | 有有效源值时使用源值；否则仅在相邻计划采样时刻均有有效 `TempDiff` 且中间无断点时，按 `[TempDiff(t_i)-TempDiff(t_{i-1})]/[(t_i-t_{i-1})/min]` 回算 | 两种路径均不可用时返回 `INSUFFICIENT_DATA`；不得当作 `0` |
| 总管代表电流 `I_bus(t)` | 同一电流段、同一时间戳取 `max(Ia(t), Ib(t), Ic(t))` | 任一必需相电流无效时，不执行依赖总管电流的规则 |
| 两小时平均总管电流 | `I_bus_2h=average(I_bus(t), 连续2h窗口)` | 窗口不完整时 D2 返回 `INSUFFICIENT_DATA` |
| 两小时负载率 | `LoadRate_2h=I_bus_2h/额定总管电流` | 额定总管电流缺失、冲突或不大于 `0` 时返回 `INSUFFICIENT_DATA` |
| 局部热点 | `目标接头TempDiff-average(同一诊断范围内全部可用连接点TempDiff)≥3K` | 热点计算所需点位不足时，依赖热点的规则返回 `INSUFFICIENT_DATA` |
| 相邻接头 | 必须由同一实际拓扑分支中的实际 Port 连续链路证明。允许前接头 `JPK` 直接连接后接头 `JPK`，或经单个直身段 `ST` 形成前 `JPK` → 单个 `ST` → 后 `JPK` 的无分支连续链路；所有相关 Port 边均须启用。不得跨 Tee、PIU、多个中间部件或未知链路，也不得仅按名称相似判断 | 不满足上述连续链路证据时不得执行 D3 |

源 `TempDiffRate` 与回算值同时存在时，源值优先，差异只用于数据审计，不反向覆盖源值。首样本、缺测恢复后的首样本及时间断点后的首样本不能回算变化率。

## 4. 公共门禁

| 门禁 ID | 门禁名称 | 触发条件 | 阻断范围 | 门禁结果 |
|---|---|---|---|---|
| G1 | 接头温升数据门禁 | 目标对象缺少有效 `TempDiff`，或点位数量、质量、连续窗口不满足目标规则 | 仅阻断对应对象的 D1、D2、D3、D5、C3、C4、C5 | `INSUFFICIENT_DATA / NONE` |
| G2 | 电流数据门禁 | 缺少规则必需的总管或分支三相电流 | 阻断依赖电流的 D2、D5、C2、C3、C4、C5 | `INSUFFICIENT_DATA / NONE` |
| G3 | 分流边界门禁 | Tee 或 PIU 后已形成实际分流，但缺少对应分支电流 | 不使用上游总管电流对分流后接头作精确判断 | `INSUFFICIENT_DATA / NONE` |
| G4 | `ConfigError` 复核门禁 | 始端单元类型、进线电流来源、接头测温方案或拓扑节点可测性中任一必需条件不成立 | 仅阻断依赖该缺失条件的规则 | `INSUFFICIENT_DATA / NONE` |
| G5 | 三相不平衡门禁 | D6 已执行 | D6 为 `MATCHED`：D5、C2 为 `NOT_APPLICABLE`；D6 为 `NOT_MATCHED`：不阻断 D5、C2；D6 为 `INSUFFICIENT_DATA`：不得假设三相平衡后继续执行 D5、C2；C3～C5 始终按各自前置条件独立判断 | D6 为 `MATCHED`：`MATCHED / NONE`；D6 为 `NOT_MATCHED`：`NOT_MATCHED / NONE`；D6 为 `INSUFFICIENT_DATA`：`INSUFFICIENT_DATA / NONE`；G5 不输出现象 |

非必需点位缺失不得扩大阻断范围。只有 `Temp`、`AmbientTemp` 或 Etemp 直身温度而没有有效 `TempDiff` 时，所有依赖接头温升的规则均失败关闭。

## 5. 六类故障现象场景

### 5.1 温升阈值超限（`TEMP_THRESHOLD_EXCEEDED`）

#### 5.1.1 现象判断

| 规则 ID | 适用对象与数据 | 判断条件 | 规则结果与输出 |
|---|---|---|---|
| D1 | 目标接头；有效、连续的 `TempDiff` | 未配置项目边界时按 `55K/60K` 判断；已配置时使用项目预警下限和立即诊断阈值 | 见下表 |

| D1 分支 | 结果 | 输出 |
|---|---|---|
| `TempDiff≥60K`，或达到已配置的立即诊断阈值 | `MATCHED` | 立即输出 `TEMP_THRESHOLD_EXCEEDED / 温升阈值超限 / EVIDENCE_ONLY`，定位命中接头并启动 Phase 2 |
| `55K≤TempDiff<60K`，或位于项目预警区间，连续 `≥5min` | `MATCHED` | 输出同上，定位命中接头并启动 Phase 2 |
| 位于预警区间但连续 `<5min` | `NOT_MATCHED` | 不启动由 D1 触发的诊断，不产生断言 |
| 数据缺失、质量无效或连续窗口被中断 | `INSUFFICIENT_DATA` | 不产生断言；恢复后从新样本重新累计 |

#### 5.1.2 根因分支

| 候选根因 ID | 中文名称 | 下游执行 | 当前可得结论 |
|---|---|---|---|
| `WATER_INGRESS` | 进水 | Phase 2 中先执行 D4；D4 命中后执行 C1 | C1 输出 `WATER_INGRESS / 进水 / ROOT_CAUSE` 并沿用 D4 的接头定位 |
| `OVERLOAD` | 负载过高 | 执行 C2 | C2 `MATCHED` 时输出根因，否则保留 D1 现象 |
| `LOOSE_BOLTS` | 螺栓未拧紧 | 执行 C3 | 仅当前 staging mock 参数完整时可确认 |
| `CONTACT_OXIDATION` | 接触面氧化或污染 | 执行 C4 | 仅当前 staging mock 参数完整时可确认 |
| `HEAT_DISSIPATION` | 散热问题 | 执行 C5 | 仅当前 staging mock 参数完整且固定集合满足要求时可确认 |

闭环：D1 未命中则结束本现象判断；D1 命中后并行执行适用的 D4、D5、C1～C5。没有 C 类规则命中时，最终只输出“温升阈值超限”及各根因规则的未命中或阻断原因。

### 5.2 温升异常（`TEMP_RISE_ABNORMAL`）

#### 5.2.1 现象判断

| 规则 ID | 适用对象与阶段 | 临时计算窗口 | 临时计算口径 | 临时阈值 |
|---|---|---|---|---|
| D5 | Phase 2 已启动；目标接头位于总管电流段或可证明未分流；G5 未命中；额定总管电流有效 | 使用以判断时刻 `t_eval` 结束、向前连续 `30min` 的窗口；窗口内全部计划采样时刻的 `Ia`、`Ib`、`Ic`、目标接头 `TempDiff` 均有效，且每个样本的 `I_bus/额定总管电流∈[90%,110%]` | 令 `x(t)=I_bus(t)²`、`y(t)=TempDiff(t)`，对 `y=a×x+b` 作带截距一元最小二乘回归，并按 `R²=1-Σ(y-ŷ)²/Σ(y-ȳ)²` 计算；有效样本不少于 3 个，且 `x`、`y` 均必须存在非零方差 | `R²_threshold=0.80` |

| D5 判断分支 | 结果 | 输出 |
|---|---|---|
| 完整窗口内 `R²≤0.80` | `MATCHED` | 输出 `TEMP_RISE_ABNORMAL / 温升异常 / EVIDENCE_ONLY`，进入后续根因判断 |
| 完整窗口内 `R²>0.80` | `NOT_MATCHED` | 温升变化具有负载驱动特征，D5 不输出本体现象，也不输出过载根因 |
| 判断时刻或窗口内负载率超出 `[90%,110%]` | `NOT_APPLICABLE` | 不执行 D5；其他适用规则继续独立执行 |
| G5 命中 | `NOT_APPLICABLE` | 三相不平衡条件下不执行 D5 |
| G5 数据不足，或窗口不连续、任一必需数据无效、有效样本少于 3 个、`x` 或 `y` 零方差 | `INSUFFICIENT_DATA` | 不产生断言；不得把不可计算的 `R²` 当作 `0` 或 `1` |

说明：D5 的连续 `30min` 窗口、最小二乘 `R²` 口径和 `0.80` 阈值是 v2 为形成闭环临时添加的规则，仅供当前下游试用，后续须由项目数据校准后替换。

#### 5.2.2 根因分支

| 候选根因 ID | 中文名称 | 下游执行 | 当前可得结论 |
|---|---|---|---|
| `WATER_INGRESS` | 进水 | 先执行 D4；D4 命中后执行 C1 | C1 直接确认进水根因并沿用 D4 的接头定位 |
| `OVERLOAD` | 负载过高 | 执行 C2 | C2 使用判断时刻电流，不使用 D5 的 `R²` 作为过载根因条件 |
| `LOOSE_BOLTS` | 螺栓未拧紧 | 执行 C3 | 满足全部 staging mock 条件时确认 |
| `CONTACT_OXIDATION` | 接触面氧化或污染 | 执行 C4 | 满足全部 staging mock 条件时确认 |
| `HEAT_DISSIPATION` | 散热问题 | 执行 C5 | 满足全部 staging mock 条件时确认 |

闭环：D5 按临时参数返回 `MATCHED`、`NOT_MATCHED`、`NOT_APPLICABLE` 或 `INSUFFICIENT_DATA`；任何结果都不得取消 D1～D3 已确认的现象，其他 Phase 2 规则继续独立执行。

### 5.3 电流负载异常（`CURRENT_LOAD_ABNORMAL`）

#### 5.3.1 现象判断

| 规则 ID | 适用对象与必需数据 | 固定执行顺序 |
|---|---|---|
| D2 | 每次只判断一个明确目标接头；完整连续 `2h` 的三相电流和该接头 `TempDiff`；有效额定总管电流；当前 mock 额定电流理想温升 `45K`；目标接头位于总管电流段或可证明未分流 | ① 先验证 `max(TempDiff,2h)-min(TempDiff,2h)∈[0K,3K]`；② 计算 `LoadRate_2h`；③ 计算 `理想温升=LoadRate_2h²×45K`；④ 计算 `偏差=2h平均TempDiff-理想温升`；⑤ 先按偏差判断，只有偏差异常才按负载率分段 |

| D2 判断分支 | 结果 | 输出 |
|---|---|---|
| 温升不稳定，或连续 `2h` 历史、额定电流、理想温升任一不足 | `INSUFFICIENT_DATA` | 不执行 D2，不产生断言 |
| 偏差位于 `[-3K,3K]` | `NOT_MATCHED` | 判定该规则下温升与负载相符；即使 `LoadRate_2h>100%` 也不由 D2 输出异常 |
| 偏差异常且 `LoadRate_2h∈[0%,40%)` | `NOT_MATCHED` | 不报警，不产生断言 |
| 偏差异常且 `LoadRate_2h∈[40%,90%)` | `MATCHED` | 输出 `CURRENT_LOAD_ABNORMAL / 电流负载异常 / EVIDENCE_ONLY`，预警并启动 Phase 2 |
| 偏差异常且 `LoadRate_2h∈[90%,100%]` | `MATCHED` | 输出同上，报警并启动 Phase 2 |
| 偏差异常且 `LoadRate_2h>100%` | `INSUFFICIENT_DATA` | 来源规则未定义该分段，失败关闭，不产生断言 |

#### 5.3.2 根因分支

| 候选根因 ID | 中文名称 | 根因规则 | 结论边界 |
|---|---|---|---|

## 8. 下游最小判断记录

下表是内部编排和解释所需的最小记录，不是 `/analyze` 的公共响应结构。

| 字段 | 必填内容 |
|---|---|
| 诊断对象 | `full_code`；若为范围规则，同时记录固定对象集合 |
| 诊断时间 | 使用的绝对开始时间和结束时间 |
| 规则 ID | 实际执行的 G、D、C 或 M 规则 ID |
| 规则结果 | `MATCHED / NOT_MATCHED / INSUFFICIENT_DATA / NOT_APPLICABLE` |
| 现象输出 | 已确认的现象 ID、中文名称、定位对象和 `EVIDENCE_ONLY` |
| 根因输出 | 仅记录 C 类 `MATCHED` 的根因 ID、中文名称、定位对象和 `ROOT_CAUSE` |
| 使用证据 | 实际使用的逻辑测点、物理定位、时间窗口、统计值和阈值 |
| 阻断原因 | 缺失数据、无效质量、绑定缺失、拓扑不确定、参数缺失或规则不适用原因 |
| 结论边界 | 明确区分“现象已确认”“根因已确认”“只有候选根因”和“无法判断” |

下游最终结论必须能够从“对象与时间范围 → 数据证据 → 规则结果 → 现象 → 根因或阻断原因”逐步回溯。任何一步缺少证据时，沿用本文件的失败关闭结果，不得由大模型补齐。
