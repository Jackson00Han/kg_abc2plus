# V11 工程 XML 映射参考配置

`topology-mapping.json` 是 `xml-declarative-mapping:v1` 的领域配置，供已上传的本体约束 XML 来源预检。它按本轮选定的 `merged/mapping.yaml` 工程映射规则整理；类型编码和端口角色属于这一来源适配，不是厂家通用编码标准。

配置只声明选择器、类型和属性映射、身份组合、归属及引用关系和未入本体字段的保留原因，不包含项目编号、设备清单或预建实例。不读取诊断包的既有实例、历史快照和点语义目录。

业务输入仍是用户选择的 `merged/sources/topology.xml` 和模拟知识文档。此配置仅处理工程 XML：保留空地址测点；`Variable.Unit` 是测量系统标识；只用显式 `Load` 建立端口连接；不补反向连接、现场读数、故障事件或根因结论。算法路径注记，包括 `staging_assumption_unverified`，仍保留在原始来源。

当前两份业务输入不足以核验测点到观测量的绑定，因此 `OBSERVES` 明确列为待定，不借模拟知识补足真实通道依据。

预检输出具有原文字符范围及对象结构锚，不是平台 ABox 实例。`valid` 表示 XML 与映射契约有效；`complete` 另外说明是否有字段缺项、身份冲突或待定引用。此阶段固定 `ontology_ready=false`、`governance_disposition=PREVIEW_ONLY`。来源登记、审核、权限和发布继续使用平台已有机制。

后续更换 XML 结构或领域时新增经过审校的配置，复用公共解析与预检代码。配置本身和每次输入的校验和一同进入构建审计，不能只凭文件名自动采用这个映射。
