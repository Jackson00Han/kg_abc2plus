# 母线槽知识库材料使用指南

当前 8002 的「母线槽知识库」已成功保存并启用本体 **v5.0.0**。拓扑已经整份处理完成（75 / 75 个片段）：41 个生成候选，29 个校验未通过，5 个无可抽取内容；候选尚未复核或发布。知识说明 Markdown 已完成来源核对，尚未上传。本指南不代表图谱已完整或页面检索已经通过验收。

## 需要选择的文件

| 文件 | 页面入口与用途 |
|---|---|
| [ontology.source.json](ontology.source.json) | 「知识构建 → 定义并发布本体」中选择原文件，用于定义类型、属性、关系及约束。 |
| [rule.references.json](rule.references.json) | 同一本体页面的「规则引用目录（按需）」中选择；仅登记外置规则的版本、校验和和条款位置。 |
| [topology.source.json](topology.source.json) | 普通业务资料上传入口；整份上传，使用 LLM 抽取工程结构、连接与逻辑测点。 |
| [busway.knowledge.md](busway.knowledge.md) | 普通业务资料上传入口；整份上传，使用 LLM 抽取概念、候选原因、范围和规则引用等知识。 |

## 操作顺序

1. 在本体页面选择 `ontology.source.json`；需要本包诊断知识的规则引用校验时，同时选入 `rule.references.json`，执行「保存并启用本体」。当前 v5.0.0 已启用，可直接核对页面状态。
2. 新建环境时，分别整份上传 `topology.source.json` 和 `busway.knowledge.md`，选择 LLM 抽取。当前工作区的拓扑已处理，可查看现有构建任务及候选，接着上传知识说明；不需要重复上传拓扑。后台负责分块，不需要手工拆文件。
3. 人工核对对象身份、属性、连接、知识含义及原文证据，处理遗漏、重复和冲突，再确认并发布。候选原因不能确认为已发生故障，测点配置不能确认为实时测量；上传成功不等于抽取完整或发布成功。
4. 选中相应知识发布版本，按 [24 道检索验收题](acceptance/busway-retrieval-cases.md) 逐题查看召回片段和引用原文，记录真实结果。

## 本体启用范围

原文件的 **22 类实体、22 类关系完整保留**。当前普通文档抽取开放其中 **18 类实体、13 类关系**；抽象类型、类型端点关系和依赖外部派生的声明不作为普通业务实例抽取或发布。

原文件 `metadata` 中的 `DRAFT` 状态和旧兼容性说明属于保留的作者版本内容，不代表当前页面运行状态。是否启用，以 8002 页面显示的本体版本与状态为准。

## 不要作为本次语料上传的文件

`acceptance/` 下的题集和报告、`ontology.template.json`、本指南，以及原始规则文件 `new_files/rule_v2.md`、实例 YAML 和映射配置，都不要与两份业务资料一起上传。`ontology.source.json` 和 `rule.references.json` 只走上述本体入口；规则执行及运行参数继续由外部服务管理。

资料来源交叉核对已单独记录在 [材料核对报告](acceptance/material-validation.json)，这不等于页面抽取、发布或检索已通过验收。
